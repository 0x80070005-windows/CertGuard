📖 Описание

CertGuard использует гибридную криптографическую схему:

    RSA-4096 — защита ключа файла (DEK)

    AES-256-GCM — аутентифицированное шифрование данных

    Argon2id — вывод ключа из пароля

    X.509-сертификаты — привязка файла к конкретному устройству

При шифровании файла генерируется случайный DEK (Data Encryption Key), который затем:

    Заворачивается публичным ключом X.509-сертификата через RSA-OAEP-SHA256

    Дополнительно шифруется ключом, полученным из пароля через Argon2id

    Резервно шифруется отдельным мастер-ключом для аварийного восстановления

Это даёт два независимых пути расшифровки: пароль + сертификат или резервный ключ.

⚠️ Ограничения

Не гарантирует защиту:

    ❌ На скомпрометированной ОС (keylogger, root-доступ)

    ❌ Когда приватный ключ на том же диске (храните на флешке!)

    ❌ В многопользовательских сценариях

    ❌ При ротации ключей (файлы привязаны к конкретному сертификату)

🔴 Критически важно

    На Windows права доступа не настраиваются автоматически

    Потеря пароля и резервного ключа = безвозвратная потеря данных

    Однопользовательский инструмент, не масштабируется на предприятие
