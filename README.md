# CertGuard - Secure File Encryption Tool

**Версия:** 1.0.0

## Описание

CertGuard - это кроссплатформенный инструмент для шифрования и расшифровки файлов с двухуровневой аутентификацией на основе устройства.

## Особенности

✅ **Кроссплатформенность** - работает на Windows и Linux
✅ **Двухуровневая аутентификация** - флешка + резервный ключ
✅ **AES-256-GCM шифрование** - военный уровень защиты
✅ **Большие файлы** - поддержка файлов > 1 ГБ
✅ **Переносимость** - один зашифрованный файл работает везде

## Требования

- .NET 6.0 или выше
- На Linux: `sudo` для создания `/mnt/temp`
- Флешка или другое устройство хранения (для основной аутентификации)

## Установка

```bash
git clone <repo>
cd CertGuard
dotnet build -c Release
dotnet run
```

## Использование

### Первый запуск (инициализация)

1. Подключите флешку
2. Запустите программу:
   ```bash
   dotnet run
   ```
3. Введите путь к флешке (например: `/mnt/usb/` на Linux или `D:\\` на Windows)
4. **Сохраните резервный ключ** в надежном месте!

### Шифрование файла

```
1 - Зашифровать файл
Введите путь к файлу: /path/to/document.pdf
Введи��е пароль: ********
✓ Файл зашифрован: document.pdf.enc
```

### Расшифровка файла

```
2 - Дешифровать файл
Введите путь к файлу: document.pdf.enc
Введите пароль: ********
✓ Файл успешно расшифрован: document.pdf
```

### Открытие .enc файла прямо

```bash
dotnet run /path/to/file.enc
```

## Архитектура безопасности

### Сертификаты хранятся в трёх местах:

**Часть 1 (16 байт)** - на флешке
```
/mnt/usb/certificate.cer (часть 1 + соль + HMAC)
```

**Часть 2 (16 байт)** - в системе
```
Linux: ~/.local/share/nautilus/tags/meta.dbnew
Windows: %AppData%/CertGuard/meta.dbnew
```

**Хеш (32 байта)** - локально
```
Linux: ~/.CertGuard/.WPS_Setting
Windows: %AppData%/CertGuard/.WPS_Setting
```

### Резервный ключ

Если флешка потеряна или повреждена, вы можете использовать резервный ключ:

```
Обычная проверка не удалась.
Введите резервный мастер-ключ: A1B2C3D4E5F6...789
Резервный ключ верный. Доступ разрешён.
```

## Технические характеристики

| Параметр | Значение |
|----------|----------|
| Шифрование | AES-256-GCM |
| Размер соли | 32 байта |
| Размер тега | 16 байт (128 бит) |
| Размер nonce | 12 байт |
| Derivation | PBKDF2 (100k итераций) |
| Целостность | HMAC-SHA256 |
| Размер чанка | 450 МБ |

## Структура зашифрованного файла

```
[Master Key Hash (32B)]
[Salt (32B)]
[Base Nonce (12B)]
[Chunk Count (8B)]
[Chunk 1]
  └─ [Length (4B)]
  └─ [Tag (16B)]
  └─ [Ciphertext (?)]
[Chunk 2]
  ...
```

## Безопасность

⚠️ **ВАЖНО:**

- Никогда не теряйте резервный ключ!

- Используйте сложные пароли для шифрования
- Регулярно проверяйте целостность флешки

## Решение проблем

### "Путь к устройству пуст"

```bash
# Linux
echo "/mnt/usb/" | sudo tee /mnt/temp/Device

# Windows
echo "D:\" > C:\Temp\CertGuard\Device
```

### "Мастер-ключ не соответствует файлу"

- Проверьте, что используется правильный пароль
- Файл может быть повреждён
- Попробуйте восстановить с резервным ключом

### "Доверенное устройство не найдено"

Используйте резервный ключ для доступа к программе и переносимым файлам.
